Copy Item to Board for monday.com

Last updated 4 November 2026

monday.com's own "duplicate to another board" drops subitems, updates and files, and leaves select columns empty when the boards do not match. This app copies the whole item, and tells you before you copy what would be lost.

Install on monday.com

Copy an item by hand

  1. On a board, open the item's ⋯ menu, then Apps › Copy to board….
  2. Pick the target board, and optionally a group. The last three destinations you used appear as shortcuts.
  3. Click Preview the copy. A table shows every column of the item and where it goes: Copied, Adapted (for example text into long text), Lost (no matching column on the target board) or Skipped (columns an app cannot write, such as formulas).
  4. Choose what to bring along — subitems, updates, a link to the original — and click Copy item. A big item takes up to a minute; a progress bar shows where it is.

Nothing is written until you click Copy item. The original item is never changed, and the copy keeps its name (no "(copy)" suffix).

Copy automatically

The app adds an action to monday.com's workflow builder: Copy item to board (with subitems, updates and files). For example, when Status changes to Won, copy the item to the Clients board.

  1. Create a workflow (+ › Workflow in your workspace) and choose a trigger, such as When status changes to something.
  2. Add an Action step and search for Copy item to board.
  3. The source board and the item are filled in from the trigger. Choose the target board and a group.
  4. Publish the workflow.

The copy runs in the background. A repeated request for the same run never creates a second copy. If the copy fails or only part of it succeeds, the run shows an error that says what was created and what is missing; the app does not retry by itself, so you never get a duplicate. Automations need a monday.com plan that includes automations. The by-hand button works on every plan.

What is copied

Part of the itemOn the copy
NameSame name, no "(copy)".
Column valuesMatched by title and type (text and long text are interchangeable, and so are status and color). Status and dropdown labels that do not exist on the target are created. Other column types are copied as they are when the target column has the same title and type.
File columnsThe same files, pointed at by reference (not downloaded or duplicated).
SubitemsAll of them, with their own values, if the target board has subitems.
Updates and repliesIn their original order, replies under their parent. Each starts with "Originally posted by … on …".
Files in updatesAttached again to the copied update.
Link to the originalA last update: "Copied from … (item …)", followed by anything that was not copied.

What is not copied

  • Columns that have no match on the target board (the preview marks them Lost). Add a column with the same title and type on the target, or copy anyway and leave them out.
  • Columns that apps cannot write, or that only make sense on their own board: formula, mirror, lookup, auto number, item ID, creation log, last updated, button, dependency, time tracking, progress, vote, connect boards and doc columns. The preview marks them Skipped.
  • The original author and time of an update. monday.com writes the copy as the person who copies, so the original author and date appear in the first line of each update instead.
  • Automations, integrations and views attached to the item or its board.

Permissions

The app works with the permissions of the person who uses it: it can only read items that person can see and only write on boards that person can edit. It asks monday.com for boards:read, boards:write, updates:read, updates:write and assets:read, and for nothing else. Details are in the privacy policy.

If something goes wrong

  • "You don't have permission to add items to that board." Ask a board owner for edit access, or pick another board.
  • "That board no longer exists…" / "…was deleted or changed in the meantime." Pick the target again.
  • "monday is busy right now." monday.com is limiting requests. Wait a minute and try again.
  • "The item was created but N steps failed." The item exists on the target board but some subitems or updates are missing. Do not copy it again: open the new item, fix what is missing by hand or delete the copy and start over.
